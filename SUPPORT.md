# Support

## Where to get help

| Need | Where |
|---|---|
| Bug report / feature request | [Open a GitHub issue](https://github.com/faidoxyz/weather-widget/issues/new/choose) |
| Question about using the plugin | Open a GitHub Discussion |
| Hermes Desktop issues | [Hermes Agent repo](https://github.com/NousResearch/hermes-agent) |
| Plugin not loading | See README. Ensure the file is at `desktop-plugins/weather/plugin.js` (exactly) |

## Before opening an issue

1. Check the [README](README.md) for install/config steps
2. Reload desktop plugins (⌘K → Reload desktop plugins)
3. Check Hermes Desktop logs (Settings → Developer → Logs)
